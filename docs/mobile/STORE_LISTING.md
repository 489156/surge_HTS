# 스토어 등재 문구 (초안 · KR)

> App Store / Google Play 등재용 초안. 포지셔닝 원칙: **"검증 기록·교육"이지 "투자 신호"가 아니다.** 과장 표현 금지 — 정직성이 규제·심사 양쪽의 방패.

## 이름 / 부제

- **앱 이름:** surge — 야간 방향 콜 기록
- **부제(Subtitle, 30자):** 예측을 박제하고 사후 검증하는 기록
- ⚠️ "surge"는 일반어라 **상표 충돌 확인 필요**(플랜 P0). 충돌 시 대체명 후보 준비.

## 프로모션 텍스트 (170자)

미국 야간 세션의 방향 예측을 세션 전에 기록하고, 실제 결과로 사후 채점합니다. 적중률·검증 지표를 숨기지 않고 그대로 공개하는 연구·교육용 기록 도구입니다. 투자자문 아님.

## 설명 (Description)

surge는 미국 레버리지·인버스 ETF 페어(예: SOXL/SOXS)의 **다음 세션 방향 예측을 사후에 검증·기록**하는 연구·교육용 앱입니다.

**무엇을 보여주나요**
- 오늘 밤 세션의 방향 예측(세션 시작 전에 박제)
- 직전 세션의 예측 vs 실제 결과 — 왜 맞았고 왜 틀렸는지
- 누적 전진 채점, 확신 구간별 실측 적중률
- anytime-valid e-value 기반 검증 진행 상황

**설계 원칙 — 정직성**
- 예측 엔진의 우위는 **아직 검증되지 않았습니다.** 앱은 이를 숨기지 않고 지표를 그대로 공개합니다.
- 성과를 과장하거나 수익을 약속하지 않습니다.

**중요 고지**
본 앱은 투자자문·매매권유가 아니며, 3배 레버리지 상품은 원금 전액 손실이 가능합니다. 모든 투자 판단과 책임은 이용자 본인에게 있습니다.
