# 개인정보처리방침 (초안)

> **상태:** 초안 — 스토어 제출 전 전문가(변호사/노무·개인정보) 1회 검토 권장.
> **적용 대상:** surge 모바일 앱(iOS/Android) 및 웹 열람 페이지.
> **시행일:** 2026-__-__ (배포일에 맞춰 확정)

## 1. 핵심 요약 — 이 앱은 개인정보를 수집하지 않습니다

surge는 **회원가입·로그인이 없으며**, 이용자의 개인정보를 **수집·저장·전송·제3자 제공하지 않습니다.** 앱은 야간 미국 세션 방향 예측의 사후 검증 기록을 **읽기 전용**으로 보여주는 정적 콘텐츠입니다.

## 2. 단말에만 저장되는 항목 (전송되지 않음)

앱은 편의를 위해 아래 값을 **이용자 기기 내부(localStorage)** 에만 저장합니다. 이 값은 서버로 전송되지 않고, 운영자가 접근·수집할 수 없습니다.

| 항목 | 목적 | 저장 위치 |
|---|---|---|
| 면책 동의 여부 | 최초 실행 면책 고지를 재표시하지 않기 위함 | 기기 로컬 |
| 화면 테마(라이트/다크) | 표시 설정 유지 | 기기 로컬 |

이 값들은 앱 삭제 또는 브라우저 저장소 삭제 시 함께 제거됩니다.

## 3. 수집하지 않는 것

- 이름·이메일·전화번호·주소 등 **식별 정보 없음**
- 위치정보·연락처·사진·기기 식별자 **수집 없음**
- **분석 도구·광고 SDK·추적기(트래커) 미사용**
- 결제·금융계좌 정보 **취급 없음**(무료·읽기 전용)

## 4. 콘텐츠 전송 및 호스팅

앱 콘텐츠(예측 기록·검증 원장)는 정적 파일로 제공됩니다. 콘텐츠를 배포하는 **호스팅 제공자**(예: GitHub Pages 등)가 서비스 운영을 위해 표준 **서버 접속 로그**(IP 주소, 요청 시각 등)를 해당 제공자의 정책에 따라 일시적으로 처리할 수 있습니다. **운영자는 이 로그를 수집·보관·분석하지 않습니다.** 오프라인 캐시(서비스워커)는 이용자 기기 내에서만 동작합니다.

## 5. 아동

본 앱은 특정 아동을 대상으로 하지 않으며, 아동으로부터 어떠한 개인정보도 수집하지 않습니다.

## 6. 이용자 권리

수집되는 개인정보가 없으므로 별도의 열람·정정·삭제 요청 대상 정보가 존재하지 않습니다. 기기 로컬 저장값은 앱 삭제로 즉시 제거할 수 있습니다.
